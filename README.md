## 关于我

我喜欢从具体的物理问题出发，追踪观测、模型和机制之间的关系。阅读论文时，我关心结论是如何建立的、哪些假设决定了解释，以及什么实验或计算能够进一步检验它。

在研究中，我重视科学准确性、证据可追溯性和结果可复现性，也希望把这些要求落实到公式、代码、图表和研究记录中。

## 研究兴趣

- **热电与横向输运**：塞贝克响应、普通与反常能斯特效应，以及相关物理机制
- **输运理论与测量**：张量关系、测量几何、符号约定与物理量提取
- **多物理场建模**：热、电及磁场相关输运问题的 COMSOL 模拟与验证
- **实验数据分析**：数据提取、单位与定义核查、拟合和不确定性分析
- **科研阅读与工具**：论文证据链分析，以及 AI 辅助的可复用研究工作流

## 工具与工作方式

- **COMSOL**：多物理场建模、参数分析与结果后处理
- **MATLAB**：实验数据处理、数值分析与科研绘图
- **Markdown / LaTeX**：研究笔记、公式整理与学术表达
- **AI 辅助研究**：文献分析、推导检查与工作流整理，并核查输出的证据和适用条件

我关注原始数据的保留、关键处理步骤的记录，以及模型、参数和结果之间的一致性。

## 近期项目

### Zhui-论文深度挖掘

一个面向凝聚态物理与热电输运论文的科研阅读 skill，用于分析论文的真实贡献、关键疑点、竞争解释和未解决问题。

它围绕 15 个科研判断问题展开，要求关键判断定位到正文、图表、公式或补充材料，并把后续想法转化为可检验的问题与最小验证方案。

**关键词**：论文深度阅读 · 证据链 · 机制判断 · 结论边界 · 可证伪假设
